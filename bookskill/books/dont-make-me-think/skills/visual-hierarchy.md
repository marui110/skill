## R (原文)

> "建立清晰的视觉层次意味着：重要的内容看起来更重要。"
> 
> "视觉层次是设计的骨架，它告诉用户应该先看什么，再看什么。"
> 
> "通过大小、颜色、对比度和留白，我们可以引导用户的视线。"

## I (自述)

视觉层次构建的核心是通过视觉手段建立信息的重要性顺序。好的视觉层次让用户能够快速理解页面结构，找到最重要的信息。这不是关于美观，而是关于信息的组织和呈现方式。

关键洞见：用户的注意力是有限的，设计应该帮助用户将注意力集中在最重要的内容上。

## A1 (书中案例)

**正面案例：苹果官网**
- 大图展示产品（最大视觉重量）
- 简洁的导航（次要视觉重量）
- 留白充足（分隔内容）
- 产品信息层次清晰

**反面案例：视觉混乱的企业网站**
- 多个元素争夺注意力
- 没有明确的视觉焦点
- 内容堆叠在一起
- 用户不知道该看哪里

## A2 (触发场景)

| 场景 | 是否触发 | 理由 |
|------|----------|------|
| 页面改版设计 | 是 | 需要重新组织信息 |
| 用户反馈页面混乱 | 是 | 视觉层次问题 |
| 信息密集页面设计 | 是 | 需要清晰层级 |
| 仪表盘设计 | 是 | 数据可视化需要层次 |
| 简单功能按钮 | 否 | 单一元素无需层次 |
| 纯文本文档 | 否 | 无视觉设计需求 |

## E (可执行步骤)

### 步骤1：确定信息优先级
- 识别最重要的内容（P0）
- 确定次要内容（P1）
- 标记辅助内容（P2）

### 步骤2：应用视觉层次技术
- **大小对比**：P0内容最大，P1次之，P2最小
- **颜色对比**：P0使用高对比度颜色
- **留白分隔**：用空白区域分隔不同优先级内容
- **排版层级**：使用不同字重和样式区分层级

### 步骤3：创建视觉焦点
- 确定页面的视觉焦点（通常是P0内容）
- 确保焦点元素最醒目
- 引导用户视线从焦点开始

### 步骤4：验证层次清晰度
- 进行可用性测试
- 询问用户："你首先看到什么？"
- 检查用户是否能快速找到重要信息

## B (边界)

### 适用范围
- 网页设计
- 移动应用
- 仪表盘设计
- 数据可视化
- 信息密集型页面

### 不适用范围
- 简单的单元素页面
- 纯文本文档
- 无视觉设计需求的场景

### 局限性
- 需要设计专业知识
- 可能受到品牌规范限制
- 需要平衡层次与美观
